# README presentation assets

`banner.svg` is an original vector composition for this repository, using the
canonical BOS API mark from `../logo.svg`. `banner.png` is its 1600 by 600 pixel
raster export. Colors follow the official website: charcoal `#0c0e14`, raised
surfaces `#141722`, champagne `#e0c99a`, and bronze `#af9566`.

The banner's application-to-model flow is illustrative. It contains no measured
performance, third-party model logos, or claims about additional security features.

`console-overview.jpg` and `security-events.jpg` are captures of the community
frontend running locally, with synthetic usage, model names, accounts, and
security-event records. They contain no production traffic or customer data.
The overview uses the native browser viewport; detailed tables continue below it.
Its navigation reflects the community profile without online system updates.
Sample costs are demonstration data, not pricing or performance benchmarks.

The README layout takes inspiration from the public
[Vary AI README](https://github.com/varium-ai/varyai/blob/main/README.md).
Its branding, screenshots, and product claims are specific to BOS API; Vary AI's
banner and screenshots are not redistributed here.

Brand reference: [BOS API official website](https://bosapi.net/).
