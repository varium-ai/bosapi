# BOS API brand assets

The canonical logo is copied from the official website at
https://bosapi.net/assets/brand.svg?v=2144318d67f0 (retrieved 2026-11-04).
The same SVG is used for the README, application logo and browser favicon.
`logo.png` is a 1024-pixel raster export of that SVG.

Official website: https://bosapi.net/

The README banner and synthetic console previews are documented in
[readme/README.md](readme/README.md). These presentation assets are separate from
the canonical application logo and favicon.
