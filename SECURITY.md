# Security policy

## Reporting a vulnerability

Report exploitable vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/varium-ai/bosapi/security/advisories/new).
Repository maintainers receive these reports through the repository's Security page.
Do not disclose vulnerabilities, real credentials, or customer data in public
issues or pull requests.

Include the affected commit or release, impact, a minimal reproduction, and a
suggested fix if available. Use synthetic credentials and payloads. Maintainers
coordinate remediation and disclosure before publishing exploit details.

## Supported versions

Security fixes initially target the current `main` branch. No older release
branches are maintained yet. Include your exact commit when reporting an issue
and update to the latest reviewed revision before checking whether it persists.

Community support does not include a guaranteed response time or an
incident-response SLA.
